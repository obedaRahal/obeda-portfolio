Graduation Project

NERD — Educational Learning & Assessment Platform

A cross-platform educational platform designed to combine learning, assessment, study planning, performance tracking, content sharing, and user interaction in one integrated system.

Flutter Dart BLoC / Cubit REST API Firebase Laravel

Overview

NERD was developed as a comprehensive educational and assessment platform supporting students throughout their learning journey. The system combines learning content, question banks, quizzes, study planning, performance analysis, social interaction, notifications, and administrative management.

Authentication & Onboarding

  • User registration, login, logout, and account management.
  • Email verification and password recovery.
  • OTP-based password reset and account recovery flows.
  • Session management and access-token handling.
  • User onboarding based on education level, university, governorate, interests, and other profile information.
  • Account-state-based navigation and access control.

Assessment & Quiz System

  • Multiple-choice quizzes with timers and answer persistence.
  • Resume functionality for incomplete assessments.
  • Flashcard-based learning with hints and knowledge rating.
  • Challenge mode with per-question timing and scoring.
  • Results, answer review, performance statistics, and progress analysis.

Study Planning & Performance Tracking

  • Study plan and task management.
  • Scheduled study activities and progress tracking.
  • Performance statistics, success rates, averages, and progress.
  • Streaks, weekly progress, and planned versus actual study time.
  • Notifications related to study activities.

Content & Community

  • Question banks with free, paid, and private content.
  • Content discovery, search, filtering, and recommendations.
  • Posts, files, images, likes, saves, comments, and reports.
  • Content access control and purchase-based access.

Architecture & Engineering

  • Feature-based application architecture.
  • Separation of data, domain, and presentation layers.
  • State management using BLoC / Cubit.
  • Reusable components and structured business logic.
  • Form validation and loading, error, and empty states.
  • REST API integration with Laravel backend services.
  • Firebase services and push notifications.

My Role

Responsible for the Flutter mobile application, implementing application features and user flows, integrating backend APIs, managing application state, handling validation and errors, building reusable components, and applying structured software architecture throughout the application.
